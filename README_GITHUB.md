# Trading AI Bot

بوت تداول آلي بالذكاء الاصطناعي — Python (تحليل بيانات) + Node.js (تنفيذ الصفقات) + React (لوحة تحكم).

## ✅ حالة هذه النسخة

هذه النسخة تحتوي على إصلاحات هندسية حقيقية تم التحقق منها يدوياً في الكود (راجع `REPAIR_REPORT.md`)، أهمها:
- إصلاح التعامل المتحفظ مع لمس SL/TP في نفس الشمعة أثناء الباك تست (كان متفائلاً بشكل غير واقعي)
- Purged/Embargo split لمنع تسرب البيانات بين التدريب والاختبار
- تنفيذ فعلي لأوامر تعديل الوقف/الإغلاق الجزئي عبر الوسيط (وليس فقط قاعدة البيانات)
- توقف البايبلاين تلقائياً عند فشل مرحلة أساسية بدل الاستمرار ببيانات ناقصة

## ⚠️ قبل التشغيل — أضف ملفات .env

هذا المستودع **لا يحتوي** على ملفات `.env` عمداً لحماية الأسرار. يجب إنشاؤها يدوياً:

```bash
cp pipeline/.env.example pipeline/.env
cp bot/backend/.env.example bot/backend/.env
```

ثم املأ القيم المطلوبة في كل ملف.

## 📌 إعداد التجربة الأولى (موصى به)

الملفات معدّة مسبقاً بإعداد مبسّط وآمن:
- **3 أزواج فقط**: EURUSD (فوركس) + XAUUSD (ذهب) + BTCUSDT (كريبتو)
- **إطار زمني واحد**: H1 (ساعة واحدة)
- **وضع Paper**: تداول وهمي بدون مال حقيقي

بعد أسبوعين من المراقبة والثقة بالنتائج (Win Rate > 54%)، يمكن التوسع تدريجياً.

## البنية

```
pipeline/     → معالجة البيانات + تدريب نماذج الذكاء الاصطناعي (Python)
bot/backend/  → محرك التداول والتنفيذ (Node.js/TypeScript)
bot/frontend/ → لوحة التحكم (React)
```

## التشغيل السريع (Windows)

```
1. SETUP_WINDOWS.bat   ← تثبيت المكتبات (مرة واحدة)
2. DOWNLOAD_DATA.bat   ← تحميل البيانات وتدريب النماذج (مرة واحدة)
3. START.bat           ← تشغيل البوت
```
